按住倒，放開停，差 1ml 都算分的手機小遊戲。

- 每局 5 杯，每杯 100 分，滿分 500
- 每局隨機出杯型、飲料和機關：越倒越快、出水口忽大忽小、冰塊、珍珠、奶蓋
- 盲倒模式：一開始倒，目標線就會消失
- 打工模式：倒差多少就扣多少店長耐心，歸零就被離職，看你能撐幾杯
- PK 模式：跟五位對手比誰倒得準，打贏才解鎖下一位

單一 `index.html`，不需要安裝或建置，用瀏覽器打開就能玩。
